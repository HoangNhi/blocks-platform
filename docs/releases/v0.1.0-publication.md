# v0.1.0 Publication

## Decision

Blocks v0.1.0 will publish the canonical engineering workspace with fresh public Git history under the MIT license.

Public scope includes:

- Product applications, services, plugins, platform code, and tests.
- Approved architecture, workflow, and contributor documentation.
- Canonical agent protocol, adapters, manifests, tools, integrations, and reviewed skill sources.
- Active fork-safe CI, Dockerfiles, safe configuration examples, and sanitized deployment templates.

Public scope excludes:

- Generated runtime mirrors, local editor or agent state, and execution output.
- Secrets, production values, infrastructure inventories, and active production deployment control.
- Personal context, private operational records, machine paths, and private development history.
- Third-party material without reviewed provenance, license, and redistribution permission.

## History

Blocks was previously developed privately. Public history begins from a reviewed and sanitized v0.1.0 snapshot so private infrastructure, credentials, runtime data, personal context, and internal development history remain excluded. The final tag target will be re-read from protected `main` immediately before tagging.

## Release Readiness

Boundary, secret, license, dependency, build, test, Docker, submodule, staged-tree, remote, fresh-clone, CI, vulnerability-reporting, and branch-protection gates have recorded passing evidence in the private execution ledger.

The public release candidate is ready for separate approval to create the annotated `v0.1.0` tag and GitHub Release. Canonical cutover, local remote/reference updates, and private repository archival remain separate approval-gated actions.
