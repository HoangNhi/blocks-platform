# Blocks v0.1.0

Blocks is an open-source .NET Aspire workspace for backend services, a React/Vite web application, shared contracts, plugin modules, and a repository-owned agent engineering protocol.

## Included

- Product applications, services, plugins, platform code, and tests.
- Approved architecture, workflow, contributor, and security documentation.
- Canonical agent protocol, adapters, manifests, tools, integrations, and reviewed skill sources.
- Fork-safe CI, Dockerfiles, safe configuration examples, and sanitized deployment templates.

## Public Boundary

The public snapshot excludes generated runtime mirrors, local editor state, execution output, secrets, production values, infrastructure inventories, active production deployment control, personal context, private operational records, machine paths, and private development history.

Blocks was previously developed in a private repository. Public history starts from a reviewed and sanitized snapshot. Third-party skill repositories remain public Git submodules pinned to reviewed commits and retain their original licenses. Clone with `--recurse-submodules`.

- Public `main` points to the protected release-preparation history.
