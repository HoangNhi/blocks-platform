## Accepted Deviation And Owner Approval

Decision `P01-LOCAL-JWT-DOTENV`, APPROVED by owner on 2026-11-01:

- Local Python reads `KNOWLEDGEHUB_JWT_KEY` from the ignored service-local
  `src/services/Blocks.KnowledgeHubService/.env`, resolved relative to `config.py`.
  An AppHost secret parameter for this local key is no longer required.
- Rationale: retain the owner's existing Python local setup rather than bridge
  a second JWT-key copy through AppHost.
- Environment variables retain precedence. AppHost still owns Python lifecycle,
  dynamic SystemService HTTPS endpoint, and Gateway destination. Other required
  settings remain explicit; no issuer/audience fallback is used.
- The key must match SystemService. The file must stay ignored/untracked and
  private; no values in Git, documentation, fixtures, shell history, or logs.
  Keep validation, TLS, and fail-closed behavior. Production provisioning is
  outside this local amendment.
- Unit tests disable real dotenv loading (`_env_file=None`); dotenv tests use
  fake temporary files.
