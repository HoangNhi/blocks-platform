# Gemini Entry Point

Read and follow, in order:

1. Current user task.
2. Root `AGENTS.md` as canonical repository instructions.
3. `agents/protocol/` and `agents/adapters/gemini.md` when present.
4. Relevant approved repository documents under `docs/`.
5. Generated bounded context under `.agent-context/generated/` when present.
6. Runtime skills only when they do not conflict with repository rules.

Do not duplicate repository rules, mutable status, or credentials here.
