# Review Workflow

## Mục đích

Chuẩn hóa review artifact và workflow improvement review.

## Artifact

| Tình huống | Artifact |
| --- | --- |
| Self-review hoặc code review | `review.md` |
| Workflow review định kỳ | `workflow-review.md` |
| Đề xuất cập nhật skill hoặc protocol | `skill-backlog.md` |
| Đánh giá migration | `migration-decision.md` |

## Quy tắc review

- Findings phải đi trước summary.
- Nếu không có finding, phải nói rõ không có finding nhưng vẫn nêu residual risk hoặc testing gap.
- Khi review workflow, ưu tiên evidence gọn và bounded thay vì broad transcript load.
