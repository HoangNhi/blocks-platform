# Superpowers Compatibility

## Mục đích

Map workflow chuẩn của Blocks với các skill tham chiếu từ Superpowers.

## Mapping chính

| Superpowers | Portable Protocol |
| --- | --- |
| `using-superpowers` | `core.md` |
| `brainstorming` | `development-workflow.md` |
| `using-git-worktrees` | `branch-workflow.md` |
| `writing-plans` | `development-workflow.md` |
| `executing-plans` | `development-workflow.md` |
| `subagent-driven-development` | `development-workflow.md` |
| `test-driven-development` | `tdd-debugging.md` |
| `requesting-code-review` | `development-workflow.md` |
| `receiving-code-review` | `development-workflow.md` |
| `finishing-a-development-branch` | `branch-workflow.md` |
| `verification-before-completion` | `verification.md` |
| `systematic-debugging` | `tdd-debugging.md` |

## Quy tắc fallback

- Nếu runtime có skill tương ứng, có thể dùng skill để tăng tốc.
- Nếu runtime không có, phải đọc protocol tương ứng trong repo và làm theo.
- Nếu có khác biệt, repo protocol của Blocks thắng vì đó là source of truth của project.
